# iOS 0.2.0 / build 13

本版本基于现有狗头军师 iOS 主 App、键盘和截图扩展。

## 修复与新增

- API 测试只读取被测服务的密钥，优先使用页面刚输入的 Key，避免其他服务钥匙串异常阻止请求。
- DeepSeek 和 OpenRouter 配置支持自定义 HTTPS Base URL / 完整 chat/completions 地址。不会自动猜测或添加 /v1。
- 策略选择“使用回复接口”时可用同一兼容服务完成判断、生成、排序，不再要求另一份 DeepSeek Key。自定义接口不请求 DeepSeek thinking 参数或 token 权重。
- JSON response_format 改为可选；连接测试发送实际文字生成请求，不要求 JSON 或 logprobs。测试成功后仍须保存配置。
- 区分 DNS、超时、证书、网络和 HTTP 错误；不记录或回显 API Key、聊天正文和服务商响应正文。
- 新增“风格”页：粘贴 / 导入 UTF-8 文本，明确标记“我：”，至少 5 条。仅发送这些本人消息，API 提炼风格后允许查看、修改、保存、关闭或删除。原始样本离开页面清空，不自动存档；风格指南存于共享配置。
- 个人风格参与候选生成、改写与排序，不替换狗头军师策略。旧配置新增字段可缺省，避免升级重置已有设置。

## 签名兼容说明

优先使用共享钥匙串。如果重签后的 Info.plist 共享组前缀失效，导致缺少 entitlement（-34018），回退到获授权 App Group 中的独立密钥文件。文件使用 iOS completeUntilFirstUserAuthentication 保护、原子写入并排除备份；不是额外的应用层加密，也不是钥匙串。配置页展示存储方式。不对锁定、损坏等其他错误静默降级。

该回退仍需要真实有效的 App Group 权限。主 App、键盘和截图扩展必须使用签名描述文件允许的同一个应用组。重签工具保留权限开关不代表证书允许该权限；软件不能补授签名中不存在的权限。缺少应用组时明确报告问题，保留键盘本地输入能力。

## 真机验收（待用户执行）

1. 用全能签签署新的 device unsigned IPA，保留键盘/截图扩展及获授权应用组，不降低 iOS 最低版本。
2. 在配置页填写安卓端已成功使用的 HTTPS 地址、模型、Key；自定义接口可填在 OpenRouter / 自定义兼容接口区域，并点“判断和回复使用自定义接口”。
3. 测试文字生成，保存配置，退出并重新打开，确认 Key 状态保留。
4. 在主 App 输入示例并分析；切换到键盘，启用完全访问，确认可生成候选。
5. 在“风格”页导入本人样本，提炼并保存，再比较键盘回复；关闭风格后确认不会使用已保存指南。
6. 测试取消请求、错误 Key、错误模型、断网，确认明确提示且不会覆盖既有风格或回复。
