# 随言键盘 0.1.0 (1) · 独立键盘验证版

这是全新源码工程，不调用旧狗头军师源码，也不依赖 App Group、共享钥匙串或云服务器。
同一 IPA 包含一个主 App 和一个键盘扩展。全能签应在一次签名中保留并签好键盘扩展。
没有特殊共享权限并不免除基本签名要求：若签名工具不能有效签署扩展，仍可能安装或启用失败。

## 安装

1. 解压下载包，将 suiyan-independent-0.1.0-unsigned.ipa 导入全能签。
2. 保留插件；不要修改 Bundle ID、最低系统版本或注入库，先用原始配置验证。
3. 安装“随言键盘”。系统设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 随言键盘 → 允许完全访问。
4. 在主 App 填写服务商 HTTPS 接口、实际模型名称、API Key 和风格规则。
5. 点击复制配置并确认。Key 包含在仅本机的剪贴板内容中，90 秒过期；App 不持久保存 Key。
6. 点主 App 的测试输入框，长按系统地球键切换随言键盘，点击“导入配置”并确认。
7. 看到“键盘独立保存并回读成功”，点击“测试连接”。导入后原配置剪贴板会清除。
8. 收起并重新切换键盘，应看到“本机配置已读取”。进一步杀掉宿主 App 再打开验证持久化。
9. 复制一小段聊天文字 → 随言键盘“读取聊天” → 核对原文 → “确认并生成” → “插入回复”。由用户手动发送。

## 数据和范围

- 配置保存在键盘私有 Application Support 的受 iOS 文件保护文件中，排除备份，不依赖钥匙串 entitlement。
- 原文与回复只在本轮内存中暂存；键盘收起时清空并取消请求。
- 只在用户点击生成时，将本轮原文和风格发送到配置的 AI 服务；连接测试不发送聊天或风格。
- 不自动读取剪贴板；识别到本应用配置格式会拒绝把它当聊天发送。
- 不记录 API Key 或响应正文到日志；HTTP 重定向被拒绝，避免向意外地址携带凭证。
- 首版只支持 OpenAI Chat Completions 的非流式文字接口，生成一条候选，可再次生成。
- 不是完整拼音输入法：普通输入请切换系统键盘。安全输入框或禁用第三方键盘的 App 不支持。
- 本版可填写风格规则，尚无自动风格提炼、截图识别、NAS 同步或账号系统。

请反馈：能否启用键盘、导入是否成功、重开后配置是否仍在、连接测试结果、能否插入回复。
